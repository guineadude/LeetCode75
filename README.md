# LeetCode 75 + Interview 150 Solutions

Comprehensive solution collections for two major LeetCode study plans: **LeetCode 75** (essential problems) and **LeetCode Interview 150** (full interview prep course).

## Structure

This repository contains two independent solution collections, each in its own folder:

- **[LeetCode75/](LeetCode75/)** — 75 essential problems organized by topic
- **[LeetCode-Interview-150/](LeetCode-Interview-150/)** — 150 interview problems organized by topic

Each folder has its own detailed README with:
- Complete topic breakdown
- Full progress tracking
- All problems organized by category with completion status

## Run a Problem

From the repository root, compile the runner with:

```bash
clang++ -std=c++23 run-problem.cpp -o run-problem.exe
```

Then run:

```bash
./run-problem.exe
```

The runner scans both study-plan folders and lets you select a completed problem to compile and run. Each solution needs its own `main` function to supply test cases.

## Getting Started

1. **New to either study plan?** Start with [LeetCode75/README.md](LeetCode75/README.md) or [LeetCode-Interview-150/README.md](LeetCode-Interview-150/README.md) for the full problem list and your progress.

2. **Adding a solution?** Place your file in the appropriate topic folder (e.g., `LeetCode75/01-Array-and-String/`) and name it with the problem number and slug: `0123-problem-slug.cpp`

3. **Tracking progress?** Check the respective README files to update the completion checkboxes as you solve problems.
